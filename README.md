## 📜 Sobre

O *2.8* é a coletânea que fecha a ponte para o *Kingdom Hearts III*: o **Dream Drop Distance HD** com Sora e Riku no Exame de Maestria, o **0.2 Birth by Sleep — A fragmentary passage** com a Aqua presa no Reino da Escuridão, e o filme **χ Back Cover**, que conta o que houve com os Videntes. Nenhum deles nunca saiu em português.

Esta tradução leva **os três para o português do Brasil** — os 10.193 trechos de texto de todos eles, mais o Diário, o menu de configurações da coletânea e as **imagens que trazem o texto desenhado dentro**.

A tradução ocupa o **slot do idioma Inglês**. Como o jogo já abre em inglês por padrão, **não é preciso mexer em opção nenhuma**: instalou, abriu, está em português.

> ⚠️ **Aviso:** esta é uma **tradução amadora**, feita por um fã, e **pode conter erros** — algum typo, uma frase com sentido um pouco diferente do original, ou uma linha que encoste na borda de uma caixa. Não é um trabalho profissional/oficial. Se encontrar algum erro, abra uma [*issue*](../../issues) com um print que eu corrijo nas próximas versões. 🙂

## 🎈 Os balões de ajuda

As telas de Ajuda do *Dream Drop Distance* explicam o jogo com balõezinhos amarelos — e o texto deles **não é legenda: está pintado na textura**. Por isso continuam em inglês na maioria das traduções de fã. Aqui, não.

Dos 67 arquivos de imagem dessas telas, **12 traziam texto pintado**, num total de **20 balões** — todos redesenhados. Os outros ou são arte pura, ou têm o balão vazio de propósito (o jogo escreve por cima na hora, e esses já saíam em português).

A letra não é uma fonte "parecida": é a **fonte da própria arte**, remontada glifo a glifo a partir dos balões que já existiam no jogo, em três idiomas. Prova de que é a certa: apagar o inglês e reescrever **o mesmo inglês** devolve a imagem praticamente igual à original, e a largura que a fonte prevê bate com a medida na arte em **99,9%**.

Onde a frase em português não cabia, **o balão é que foi esticado** — repetindo uma coluna do miolo dele, que é liso. Nenhuma letra precisou encolher.

## 💾 Instalação

> **Requisitos:** só o jogo instalado pela **Steam**. Não precisa instalar ferramenta nenhuma, nem mexer em Proton, variável de ambiente ou opção de inicialização — o pacote já traz tudo o que usa.
>
> **Feche o jogo antes de instalar.**

Baixe o pacote na página de [**Releases**](../../releases/latest).

### 🪟 Windows — automático (recomendado)

1. Baixe e **descompacte** o `.zip`.
2. Dê **duplo-clique** em `instalar.bat`.
3. Ele acha a pasta do jogo sozinho, em qualquer biblioteca da Steam, **inclusive em outro disco**. *(Se não achar, ele diz como apontar o caminho.)*
4. Pronto. Abra o jogo — já está em português.

O instalador **guarda uma cópia de cada arquivo original** antes de tocar nele, com o nome `<arquivo>.original` ao lado. Para voltar atrás, é só rodar `desinstalar.bat`.

### 🖐️ Windows — manual (copiar e colar)

Se preferir não rodar script nenhum:

1. Abra a pasta do jogo *(na Steam: botão direito no jogo → **Gerenciar** → **Explorar arquivos locais**)*.
2. **Faça uma cópia** dos arquivos abaixo, renomeando cada um para terminar em `.original`.
3. Aplique os patches com o `xdelta3.exe` que vem na pasta `patch`, abrindo o Prompt de Comando ali dentro:
   ```
   xdelta3.exe -d -f -s "CAMINHO\Image\SettingMenu.pkg.original" SettingMenu.pkg.xdelta "CAMINHO\Image\SettingMenu.pkg"
   xdelta3.exe -d -f -s "CAMINHO\Image\Launcher28.pkg.original"  Launcher28.pkg.xdelta  "CAMINHO\Image\Launcher28.pkg"
   xdelta3.exe -d -f -s "CAMINHO\Image\dt\kh3d_first.pkg.original" kh3d_first.pkg.xdelta "CAMINHO\Image\dt\kh3d_first.pkg"
   xdelta3.exe -d -f -s "CAMINHO\Image\dt\kh3d_fourth.pkg.original" kh3d_fourth.pkg.xdelta "CAMINHO\Image\dt\kh3d_fourth.pkg"
   ```
4. Copie por cima os quatro `.hed` da pasta `patch`, cada um para a mesma pasta do `.pkg` de mesmo nome.
5. Copie `TresGame-WindowsNoEditor_1_P.pak` para `KINGDOM HEARTS 0.2 Birth by Sleep\Content\Paks\`.

### 🎮 Steam Deck

1. **Feche o jogo** e vá para o **Modo Área de Trabalho**.
2. Copie a pasta descompactada para o Deck (ex.: `~/Downloads`) — pelo cabo USB é o mais rápido.
3. Abra o **Konsole** e rode:
   ```bash
   cd ~/Downloads/KH28_PTBR
   bash instalar_deck.sh
   ```
4. Ele detecta o jogo no SSD **ou no cartão SD**.
5. Volte ao **Modo Jogo** e abra — já está em português.

> 💡 Rode com `bash instalar_deck.sh` mesmo, e não `./instalar_deck.sh`: o bit de execução se perde quando o arquivo passa pelo Windows.
>
> ✅ **Não precisa instalar nada antes.** O SteamOS não traz o `xdelta3` e tem o sistema somente-leitura, então o pacote leva o aplicador de patch em **Python puro** — e o Deck já vem com Python 3. Se o `xdelta3` estiver instalado, ele é usado por ser um pouco mais rápido; nenhum dos dois é obrigatório.

### ↩️ Para desinstalar

- **Windows:** duplo-clique em `desinstalar.bat`.
- **Steam Deck:** `bash instalar_deck.sh --tirar`.
- **Sempre funciona:** na Steam, botão direito no jogo → **Propriedades** → **Arquivos instalados** → **Verificar integridade**.

## 📦 O que o patch mexe

| Arquivo | Onde | O que leva |
|---|---|---|
| `kh3d_first.pkg` / `.hed` | `Image\dt\` | o texto e as imagens do Dream Drop Distance |
| `kh3d_fourth.pkg` / `.hed` | `Image\dt\` | os diálogos de seis mundos do DDD (La Cité des Cloches, The Grid, Prankster's Paradise, Country of the Musketeers, Symphony of Sorcery, The World That Never Was) |
| `Launcher28.pkg` / `.hed` | `Image\` | o Back Cover, o Diário e a tela inicial da coletânea |
| `SettingMenu.pkg` / `.hed` | `Image\` | o menu de configurações |
| `TresGame-WindowsNoEditor_1_P.pak` | `KINGDOM HEARTS 0.2...\Content\Paks\` | o KINGDOM HEARTS 0.2 *(arquivo novo, não substitui nada)* |

Os `.pkg` são grandes demais para caber num repositório, então o que se distribui é o **patch binário** de cada um — 27 KB, 74 KB, 4,9 MB e 77 KB. O instalador reconstrói o arquivo a partir do seu próprio original, o que também garante que **a versão do seu jogo é a esperada**: se o tamanho não bater, ele para e avisa em vez de estragar a instalação.

O patch é aplicado pelo `xdelta3.exe` que vem no pacote ou, se ele faltar, pelo **`aplicar_patch.py`**, que faz o mesmo trabalho em Python puro e sem dependência nenhuma além da biblioteca padrão. É o que dispensa instalar qualquer coisa no Steam Deck. Os dois caminhos foram testados e produzem **exatamente o mesmo arquivo**, conferido por md5.
